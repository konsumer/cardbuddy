cardbuddy

Swap, back up and recover the M-VAVE FM-1's firmware, and manage its sounds, samples and songs, from an M5 Cardputer: a keyboard instead of a touchscreen.

Open source on GitHubFree, GPL-3.0: read it, change it, build it yourself.

The Cardputer sibling of fm1buddy and lilfm1buddy. Same SD card as fm1buddy: move it between them and both see the same firmwares, backups and sounds.

Install M5 Launcher Use it

You need

  • An M5 Cardputer (the ADV, or the original), and a microSD card in it (FAT32).
  • A powered USB hub (or a USB-C OTG adapter with a charging port), for the FM-1 and your MIDI controllers. For recovering an FM-1 that won't start, a USB-C cable straight to it.
  • Chrome or Edge on a computer, and a USB-C cable that carries data

Using M5 Launcher? You don't need to install it this way: cardbuddy is an app like any other there, and Launcher stays on the Cardputer. See the M5 Launcher tab.

1. Download mode

  1. Switch the Cardputer off (the switch on its side).
  2. Plug it into this computer with the USB-C cable.
  3. Hold its G0 button, switch it on, then let go. The screen stays dark: that's download mode.

No port to pick? Do this again: it has to be off before you plug it in. Running cardbuddy, the Cardputer's USB-C port is a USB host (for the FM-1 and your controllers) unless a computer is on it as it starts, so a Cardputer plugged in while it's on shows no port. Download mode always does. Still nothing: try another cable (some only charge), and on Linux, check you can use serial ports (the dialout group).

2. Install

Press Install, and pick the Cardputer's port (USB JTAG/serial debug unit, or similar). Let it erase the first time.

This replaces what's on the Cardputer's flash, M5 Launcher too. The SD card isn't touched.

Your browser can't: use Chrome or Edge on a computer. This page has to be opened over https.

No build yet: the page has no firmware next to it.

3. Start it

When it's done, switch the Cardputer off and on again (or press its reset button). cardbuddy starts, and makes its folders on the SD card the first time.

4. Firmwares

Two ways to get them:

  • From the Hub, over Wi-Fi: set it up in Settings > Wi-Fi, then Firmware: Hub has every FM-1 firmware on mutant.cloud.
  • From your computer: put .fwsc files in /fm1 on the SD card. USB disk on the Cardputer makes the card a drive on your computer (it comes back by itself when you eject it), or use a card reader.

How to use it

M5 Launcher keeps several apps on the Cardputer and starts the one you pick. cardbuddy is one of them: the Cardputer can run other things when you don't need it.

From the SD card

  1. Get cardbuddy.bin: the latest release.
  2. Copy it onto the Cardputer's SD card (anywhere: the card's top level is fine).
  3. In Launcher: SD, pick cardbuddy.bin, then Install. Launcher starts it.

Launcher shows its own screen for a moment each time the Cardputer starts: press a key then to get back to it, and pick something else.

Install a firmware

  1. Plug a powered USB hub into the Cardputer's USB-C port, and the FM-1 (switched on) into the hub.
  2. On the Cardputer: Firmware: SD card (or Firmware: Hub), pick one, enter.
  3. cardbuddy sends the FM-1 into its boot loader and writes it. If it asks, switch the FM-1 off, then on.
  4. The FM-1 restarts with its new firmware.

Back up and recover

  1. Backup & recover saves the FM-1's whole flash to /backups. Do this first, before trying firmwares.
  2. An FM-1 that won't start: plug it straight into the Cardputer (no hub), pick a firmware or a backup to bring it back with, and switch the FM-1 on when cardbuddy says. The flash map is drawn on both screens as it goes.

Everything else

  • Sounds: send .syx banks, save the stock firmware's voice, keep and load fomajam's songs and kits, SLOOP backups, projects, songs and samples (.wav).
  • MIDI: the devices on the hub, routing between them (r, with /midimap.txt: make one on fm1buddy's MIDI map page), Bluetooth MIDI (b).
  • Keys: the keyboard as a MIDI controller, two octaves laid out as in trackers (z s x d c v… and q 2 w 3 e r…), - = octave, [ ] channel.
  • USB disk: the SD card as a drive on a computer.
  • Settings: Wi-Fi, theme, brightness, Bluetooth MIDI, USB MIDI on a computer.

Nothing is written to the FM-1 until you pick something, and its boot loader is in its ROM: nothing here can make it unrecoverable.
